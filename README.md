## 🚀 Active Flight Operations & Deployed Payloads

### 1. 📡 [airQ] — IoT Multi-Sensor Telemetry & Environmental Ground Station
*ESP32, Embedded C/C++, Multi-Sensor Fusion, JSON Telemetry, Vanilla Web Dashboard*
- **Architecture:** Engineered an end-to-end telemetry acquisition unit using an **ESP32** microcontroller interfacing gas, relative humidity, and particulate matter (PM) sensors.
- **Data Pipeline:** Serialized live sensor streams into structured **JSON telemetry packets**, establishing real-to-digital data pipelines for real-time environmental monitoring and anomaly detection.
- **Flight Display:** Designed a responsive web dashboard parsing live streams to track air quality indices without high-overhead frameworks.

### 2. 🚢 [TradeJapan] — Automotive Global Export & RESTful Backend Platform
*Java Spring Boot, RESTful APIs, MySQL, HTML5/CSS3, JavaScript*
- **Architecture:** Architected a modular enterprise backend with clear controller-service-repository layers to process vehicle inventory and export logistics.
- **Data Engineering:** Designed and optimized a relational **MySQL schema** supporting parameterized inventory search, filtering algorithms, and transactional consistency.
- **System Integration:** Built and documented robust **RESTful API endpoints** for decoupled client-server data synchronization.

### 3. ⚡ 4-Bit Arithmetic Logic Unit (ALU) & 6x4 Memory Subsystem
*Intel Altera Quartus, NI Multisim, Digital Logic Design, Waveform Synthesis*
- **Logic Core:** Designed, synthesized, and verified an 8-operation **4-bit ALU** integrated with a dedicated **$6 \times 4$-bit addressable localized memory matrix**.
- **Verification:** Built cross-platform testbenches in **NI Multisim** and **Intel Altera Quartus**, validating hardware status flags (**Carry, Zero, Overflow/Sign**) and resolving race conditions through timing waveform analysis.

### 4. 🧮 Python Interactive Computational Engine & Calculator
*Python 3, Modular Design, Exception Pipelines, CLI*
- **Engine:** Built a modular mathematical expression evaluator with operator precedence parsing and arithmetic pipeline execution.
- **Resilience:** Implemented strict input sanitization and exception handling routines (zero-division traps, type validation) following **PEP 8** clean-code standards.

### 5. ⏱️ Sequential Step-Up Digital Counter Circuit
*Proteus Design Suite, Sequential Logic, Flip-Flop State Networks*
- **State Machine:** Designed, wired, and simulated a clock-driven step-up counter verifying synchronous/asynchronous state progression and display output decoding.

### 6. 🎮 Deterministic CLI State & Logic Engine (Tic-Tac-Toe)
*C, Memory Management, Procedural State Machines*
- **State Evaluation:** Engineered an interactive CLI state machine in pure C with 2D coordinate mapping, low-overhead terminal rendering, and deterministic win/draw algorithms.
